# VS Code assetの由来

extension iconは組み込みのOpenAI画像生成workflowを使い、このrepository専用に作成しました。
外部logo、screenshot、顧客data、stock assetは入力していません。

syntax highlighting screenshotは`source/vscode-syntax-demo.html`をbrowserで決定的にrenderした
ものです。架空のworkspace名とdemo SQLだけを含み、private dataやthird-party artworkなしで
再生成できます。
