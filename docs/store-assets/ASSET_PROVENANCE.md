# VS Code asset provenance

The extension icon was created specifically for this repository with the built-in OpenAI image
generation workflow. No external logo, screenshot, customer data, or stock asset was supplied.

The syntax-highlighting screenshot is a deterministic browser render of
`source/vscode-syntax-demo.html`. It contains only fictional workspace names and demo SQL and can
be regenerated without access to private data or third-party artwork.
